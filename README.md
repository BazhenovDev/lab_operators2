## Требования

Установленный .NET SDK 10: https://dotnet.microsoft.com/download/dotnet/10.0

## Установка и запуск

1. Скачайте репозиторий.

2. Перейдите в папку проекта:

   ```bash
   cd Lab_Operators_2
   ```

3. Запустите нужную программу:

   Программа 1:

   ```bash
   dotnet run --project Task1
   ```

   Программа 2:

   ```bash
   dotnet run --project Task2
   ```

   Программа 3:

   ```bash
   dotnet run --project Task3
   ```

   Программа 4:

   ```bash
   dotnet run --project Task4
   ```

4. Введите данные по подсказкам в консоли. Каждое число вводите с новой строки.
